## My current project: ToolMelo

[ToolMelo](https://toolmelo.com/en) is a free browser toolbox for everyday file tasks. No signup, no ads. Available in English, 中文 and 日本語.

- **PDFs:** merge, split, organize pages and export pages as images.
- **Images:** compress to a target size in KB, resize, crop and convert formats.
- **Markdown:** format articles and export to Word, HTML or images.
- **QR codes:** generate codes and read their contents.

The PDF, image and Markdown file tools process files locally in your browser. The separate web image extractor uses a server to fetch images; experimental decision helpers send inputs through the server to Jev.
